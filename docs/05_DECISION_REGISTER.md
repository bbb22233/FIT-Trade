## 2. 决策解释

### 2.1 `D-039` 与外部数据权限

由于第一版不接入外部数据，“外部数据是否可以触发交易”不适用。未来新增数据源时必须重新做权限决策，不能默认允许触发实盘。

### 2.2 `D-050` 与 `D-051`

单台服务器可以通过持续 WAL 归档、远程备份、基础设施脚本和预构建恢复流程接近 RPO 1 分钟、RTO 15 分钟，但无法提供与热备相同的保证。因此 `D-051` 是工程目标，不是可承诺 SLA。

### 2.3 `D-052` 的适用范围

直接小额主网只适用于用户指挥、明确确认后的交易。它不取消：

- 单元、集成、契约和故障注入测试
- 主网只读核对
- 小额和资金上限
- 强制止损
- Kill Switch

它也不允许自动交易跳过历史验证、影子运行、独立模型审核和用户批准。

### 2.4 `D-049` 的风险

只使用账户密码恢复会把恢复安全集中到一个凭证。第一版必须使用强密码哈希、限速、异常告警和会话撤销。未来多用户商业版需要重新评估恢复码、Passkey 和已有设备批准。

这些问题不会改变当前总体架构，但必须在相应实现阶段确定：

- 具体模型供应商、模型名称和 API 路由
- 图表组件与许可方案
- Email 和 iOS Push 服务
- Linux 云服务商和部署区域
- 远程备份目标及加密密钥管理

- 小额主网的初始资金上限
- 候选版本的最少样本、影子周期和风险指标
