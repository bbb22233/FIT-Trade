## 4. 产品边界

### 4.1 本版本包含

- Hyperliquid 永续合约
- BTC、ETH、SOL 实盘白名单
- 个人用户与多个交易账户的数据模型
- Hermes 内置聊天
- 用户指挥后的真实主网交易
- 市价单、GTC、Post Only/ALO
- 强制 Stop Market 保护
- 灵活止盈和用户指挥的移动止损
- 全仓与逐仓
- 用户指定杠杆
- 交易风格学习、复盘和候选版本
- 受限自动交易
- 网页、Tauri 桌面软件和后续原生 iOS

### 4.2 本版本不包含

- MT5、外汇经纪商和 Windows VPS
- 现货交易
- BTC、ETH、SOL 之外的实盘品种
- 完整 L2 盘口和逐笔成交存储
- 新闻、社交情绪、链上或宏观外部数据
- 托管、充值、提现和资金划转
- 公开注册、收费订阅、KYC/AML 和商业运营后台

### 4.3 未来扩展但当前不实现

- 多用户商业版
- 更多交易所适配器
- 更多实盘品种
- 多服务器高可用
- 外部研究数据
- MT5 经纪商执行节点

## 5. 变更规则

- 改变白名单、签名边界、确认规则、止损规则或自动交易授权属于重大变更。
- 重大变更必须同步更新产品需求、架构、验收标准和决策记录。
- 风险参数的具体数值属于用户配置，不需要修改需求文档，但必须产生版本化审计记录。
- 实现不得通过“临时兼容”“默认值”或 Agent 提示词绕过固定需求。
