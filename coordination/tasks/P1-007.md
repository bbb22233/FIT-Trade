- Server Codex uses a detached read-only worktree for Linux, PostgreSQL, NATS,

- Local Hermes uses a read-only filesystem and no MCP/tool connection to the
  integration harness. It receives no database, NATS, wallet, exchange, or
  service credential. From pre-generated immutable evidence and contract
  fixtures, it checks: body/header/query/MCP/WebSocket identity injection;
  Enrollment versus Device Action Challenge field separation; replay,

  prove the MCP and external-integration tool inventories are empty and no MCP
  server or integration-harness connection was configured or opened. Only
  read-only local file/command inspection is allowlisted; otherwise its review
  is invalid and P1-007 fails.
- No reviewer may repair the candidate. Any finding returns to a new bounded
  descendant task owned by the relevant component owner.
- Findings are combined by union, never vote or majority. Local Codex cannot
